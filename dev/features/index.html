    Page What's inside

    Types and conversions Field, Slice and As, the built-in conversions, conversions of your types
    Absent values nil pointers, nil slices and nil nested structs: which rules skip them

    Rules¶

    Page What's inside
    Strings str.Of: Required, lengths, AnyOf, Prefix, Suffix, Contains, Regexp, Email, URL, IP, Hostname, UUID, Alphanumeric, Trim
    Numbers num.Of and num.Ptr: Required, Min, Max, AnyOf, AnyOfInterval
    Time timex.Of: Required, Before, After, Between, InPast, InFuture
    Comparable values eq.Of, eq.Ptr, eq.Slice: enums, bools — Required, OneOf, NotOneOf, Equal, NotEqual, Unique
    UUID uuid.Of of the separate module: Required, AnyOf
    Slices Slice, str.Slice, uuid.Slice: length rules, Each for elements
